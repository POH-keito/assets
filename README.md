# assets

公開 URL が必要な小さなアセットを置く。**秘密を含むものは置かない。**

| path | 用途 |
| --- | --- |
| `webhook-avatars/exposure-monitor.png` | Google Chat の incoming webhook アバター (`POH-keito/exposure-monitor` の通知用) |

## 参照の仕方

```
https://raw.githubusercontent.com/POH-keito/assets/main/<path>
```

Google Chat の webhook はこの URL を取得しに行くので、repo は public のままにする。
